# MD Saiham — Floating Glass Website (fixed assets)

## Upload instructions
1. Extract this ZIP.
2. Upload **all contents together** to the root of your GitHub Pages repository (`main` / `/`).
3. Keep the `assets` folder and its subfolders next to `index.html`; do not upload only the HTML file.
4. Keep the `CNAME` file containing `www.saiham.online`.
5. Commit changes and wait for GitHub Pages to deploy.

## Included assets
- `assets/logos/`: BRAC Bank, Dubai Islamic Bank, bKash, BOTIM, du Pay, imo
- `assets/images/`: profile photo, ALF ZAIN logo, cover poster
- `assets/videos/cover.mp4`: 1920×1080 Full HD cover video
